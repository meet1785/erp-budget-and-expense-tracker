# Machine Learning Algorithms - Complete Package

This package contains 5 fundamental machine learning algorithms with complete implementations, visualizations, and datasets.

## Quick Start

```bash
pip install -r requirements.txt
python linear_regression.py
python decision_tree_classifier.py
python kmeans_clustering.py
python hierarchical_clustering.py
python apriori_algorithm.py
```

## Algorithms Included

1. **Linear Regression** - Predict continuous values
2. **Decision Tree Classifier** - Classify data into categories
3. **K-Means Clustering** - Group similar items together
4. **Hierarchical Clustering** - Create hierarchical cluster relationships
5. **Apriori Algorithm** - Find patterns in transactional data

## Output Files

Each script generates visualizations (PNG) and data files (CSV) showing algorithm results.
